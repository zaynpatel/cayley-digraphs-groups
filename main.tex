This talk demonstrates a relationship between \textbf{group} theory and \textbf{graph} theory. \bigskip

We will learn about Cayley digraphs of groups which visualize groups as a directed graphs. \begin{frame}
\frametitle{Generators and relations}
    \begin{itemize}
        \item<1-> Generators and relations are special elements we can combine, via the group operation, to get any other element in the group.
        \item<2-> Groups with a single element that combines with itself to generate the entire group are called \textbf{cyclic}. Recall that we can also have subgroups which are cyclic.
        \item<3-> Most groups we have worked with are not cyclic and have multiple generators. $D_{4}$ has $R_{90}$ and $H$ as generators. 
        \item<4-> We call the set of generators of $G$ the \textbf{generating set} which is usually denoted $S$. For $D_{4}$, $S = \{R_{90}, H\}$.
    \end{itemize}
\end{frame}

\begin{frame}
\frametitle{Generators and relations}
    \begin{itemize}
        \item<1-> Relations definition: the smallest set of equations that specify the conditions the generators must satisfy. In $D_{4}$ $R^{4} = H^{2} = (RH)^{2} = R_{0}$.
        \item<2-> Because this is the minimal set, we can derive all additional relations from this set.
        \item<3-> If two groups are defined by the same relations, they are isomorphic.
        \item<4-> Describing a group by its generators and relations is called a \textbf{group presentation}. The presentation for $D_{4}$ is $\langle R, H | R^{4} = H^{2} = (RH)^{2} = R_{0}\rangle$.
        \item<5-> In order to define generators and relations rigorously, we need a beautiful concept called free groups. More information is available in the appendix if you are interested.
    \end{itemize}
\end{frame}

\begin{frame}
\frametitle{Cayley digraphs of Groups}
\begin{block}{Definition: Cayley digraph of a Group}
Let $G$ be a finite group and let $S$ be a set of generators for $G$. We define a digraph $Cay(S:G)$, called the Cayley digraph of $G$ with the generating set $S$, as follows:
    \begin{enumerate}
        \item Each element of $G$ is a vertex of $Cay(S:G)$
        \item For each $x$ and $y$ in $G$, there is an arc from $x$ to $y$ if and only if $xs = y$ for some $s$ $\in S$.
    \end{enumerate}
\end{block}
\end{frame}

\begin{frame}{Graph Theory meets Group Theory}
\only<1>{Hamiltonian paths and circuits are not unique; in any given graph, we may find multiple paths that satisfy the definition.

There is a condition about Hamiltonian circuits and generators that is important enough to prove.}

\only<1>{\textbf{Claim:} If $s_{1}, s_{2}, ..., s_{n}$ is a sequence of generators determining a Hamiltonian circuit, then the same sequence determines a Hamiltonian circuit for any starting vertex.}

\pause

\begin{proof}
Let $s_{1}, s_{2}, ..., s_{n}$ be a sequence of generators determining a Hamiltonian circuit. In addition, let $v_{1}, v_{2} \in G$. Since we have a Hamiltonian circuit we know that $v_{1}s_{1}s_{2}...s_{n} = v_{1}e$. By the cancellation property for groups $s_{1}s_{2}...s_{n} = e$. \pause

Now take another vertex, $v_{2}$ and let $v_{2}$ be the starting vertex. By the same argument as $v_{1}$ we know that $v_{2}s_{1}s_{2}...s_{n} = v_{2}e$. After applying the cancellation property $s_{1}s_{2}...s_{n} = e$. \pause

Thus we have shown that for two different, arbitrary starting vertices the same sequence results in a Hamiltonian circuit.
\end{proof}
\end{frame}

\textbf{Claim:} There is no Hamiltonian circuit in $\mathbb{Z}_{m} \oplus \mathbb{Z}_{n}$ when gcd(m, n) = 1.

\begin{frame}{Hamiltonian circuits in Cay($\{(1, 0), (0, 1)\}: \mathbb{Z}_{m} \oplus \mathbb{Z}_{n}$)}
\begin{proof}
    Suppose there is a Hamiltonian circuit in the digraph and we start at some vertex $(a, b)$ which exits horizontally. \medskip \pause 

    If $(a, b)$ exits horizontally then $(a - 1, b + 1)$ must also exit horizontally otherwise it will pass through $(a, b + 1)$ twice. Now, $(a - 2, b + 2)$ must exit horizontally otherwise it will pass through $(a - 1, b + 1)$ twice. \medskip \pause

    When we repeat this argument we see that every vertex will need to exit horizontally. But, if we exit each vertex horizontally we cannot have a Hamiltonian circuit. Thus we get a contradiction; there is no Hamiltonian circuit for a digraph with $gcd(m, n) = 1$. \medskip
\end{proof}
\end{frame}

\begin{frame}{Hamiltonian circuits in Cay($\{(1, 0), (0, 1)\}: \mathbb{Z}_{m} \oplus \mathbb{Z}_{n}$)}
Now we look at the special case where $gcd(m, n)$ $>$ $1$.

\textbf{Claim:} Cay($\{(1, 0), (0, 1)\}): \mathbb{Z}_{m} \oplus \mathbb{Z}_{n}$ has a Hamiltonian circuit when $n \mid m$.
\begin{proof}
    \only <1>{By hypothesis we know that $m = nk$ for some $k$ $\in \mathbb{Z}$. We want to prove the claim using a coordinatized digraph similar to our previous theorem. Since the $gcd(m, n) >1 $ we have an external direct product of the form $\mathbb{Z}_{nk} \oplus \mathbb{Z}_{n}$. This product has $n^{2}k$ elements. The external direct product has $n^{2} = n \times n$ elements $k$ times. So the coordinatized digraph has $k$ $n \times n$ blocks.}

    \only<2>{To form a Hamiltonian circuit we begin at the vertex $(0, 0)$ and cover the vertices in the first block by using the generator $(0, 1)$ until the last vertex in the first row is reached. Then apply the generator $(1, 0)$ to move vertically and continue this process of applying $(0, 1)$ to move horizontally and $(1, 0)$ to move vertically for each of the $k$ blocks until the vertex $(n - 1, 0)$ has been reached. We move vertically to the next block and repeat this process until the last vertex in the $k$th $n \times n$ block.}

    \only<3>{Now, the left-most vertex in the last block is $(nk - 1, 0)$ and this needs to exit horizontally or vertically, by definition. Apply the generator $(1, 0)$ to this vertex. Then $(nk - 1, 0) + (1, 0) = (nk - 1 + 1, 0) = (nk, 0)$. Recall that our external direct product is $\mathbb{Z}_{nk} \oplus \mathbb{Z}_{k}$ so we can apply the group operation to $nk$ s.t. $nk \ mod \ (nk) = 0$.

    Thus, $(nk - 1, 0)$ exits vertically to $(0, 0)$ completing the Hamiltonian circuit.}
\alt<3>{\qedhere}{\phantom\qedhere}
\end{proof}
\end{frame}

\begin{frame}{Abelian Groups Have Hamiltonian Paths}
\begin{theorem}
    Let $G$ be a finite Abelian group, and let $S$ be any generating set for $G$. Then $Cay(S:G)$ has a Hamiltonian path.
\end{theorem}

\begin{proof}
    \only<1>{We use induction on $|S|$. If $|S| = 1$, say, $S = {\{a\}}$, then the digraph is just a circle with labels $e, a, a^{2}, ..., a^{m-1}$, where $|a| = m$. There is a Hamiltonian path for this case; it is just the path around the circle.}

    \only<1>{Now assume that $|S| > 1$. Choose some $s \in S$. Let $T = S - {\{s\}}$. Define $H = \langle s_{1}, s_{2}, ..., s_{n-1} \rangle$ where $H \leq G$ and $H$ could be equal to $G$. $H$ contains all possible combinations of the generators $s_{1}, s_{2}, ..., s_{n-1}$, and although $H$ contains one less generator than $S$ we can still generate $G$ because it is possible that $S$ contains redundant generators. There is no constraint in the hypothesis that $S$ is the minimal set of generators.}

    \only<2>{Because $|T|$ is less than $|S|$ and $H$ is a finite Abelian group, the inductive hypothesis guarantees that there is a Hamiltonian path $(a_{1}, a_{2}, ..., a_{k})$ in $Cay(T:H)$.} 
    
    \only<2>{The $a_{i}$ represent the generators in $T$ and their products give elements in $H$ (since $T$ generates $H$). We use this notation because we want to add generality about how the generators are combined to give an element $s^{i_1}_{1}s^{i_2}_{2}...s^{i_n-1}_{n-1} \in H$.}

    \only<2>{We want to show that there is a Hamiltonian path in $Cay(S:G)$. We will take advantage of the fact that we have a subgroup $H$ and we can take any element $g \in G$ and form the left coset $gH$. Now note that $gH$ is an element of $G/H$.}
    
    \only<3>{We can form this factor group because $G$ is Abelian and its subgroups $H$ are also Abelian and normal.}

    \only<3>{Each $g \in G$ looks like $g = s^{i_1}_{1}s^{i_2}_{2}...s^{i_n}_{n}$ since any element in $G$ is a combination of elements in the generating set. So $gH = s^{i_1}_{1}s^{i_2}_{2}...s^{i_n}_{n}H = [(s^{i_{1}}_{1}s^{i_{2}}_{2}...s^{i_{n-1}}_{n-1})H] \cdot [s^{i_{n}}_{n}H]$.}

    \only<3>{But $(s^{i_{1}}_{1}s^{i_{2}}_{2}...s^{i_{n-1}}) \in H$ so this collapses to $H$ or $eH$ because of the coset property that $aH = H$ if $a \in H$.}
    
    \only<3>{Thus, we get $eH \cdot s^{i_{n}}_{n}H = s^{i_{n}}_{n}H$; this follows from coset multiplication rules. So the elements of $G/H$ look like $s^{i_{n}}_{n}H$. The book notates this as $s^{n}H$ so we will use this notation for the remainder of the proof.}

    \only<4>{Now we can see that $G/H = \{s^{0}H, s^{1}H, ..., s^{n}H\}$. We conclude that $sH$ generates the factor group $G/H$ and also note that this partitions the group $G$ into cosets of the form $s^{0}H, s^{1}H, ..., s^{n}H$.}

    \only<4>{We will use these cosets to form the Hamiltonian path in $Cay(S:G)$. We begin in the first coset, H, and start from the identity element of $G$, which is in $H$ because $H \leq G$, the path given by $(a_{1}, a_{2}, ..., a_{k})$ visits each element of H exactly once because $(a_{1}, a_{2}, ..., a_{k})$ is a Hamiltonian path in $Cay(T:H)$. Because we partitioned G into these $n$ cosets we are treating each distinct coset as a $Cay(T:H)$ digraph.}

    \only<5>{When we do this, the inductive hypothesis says that there exists a Hamiltonian path in $Cay(T:H)$, the generator $S$ moves to the next coset and we apply the same idea until the last element in the last coset.}

    \only<5>{The vertices of $Cay(S:G)$ are elements of $G$ and these elements are in exactly one coset $sH^{i}$ because of the partition fact referenced earlier. Since we visited each element in each coset $sH^{i}$ this implies that we visited each vertex of $Cay(S:G)$ exactly once. Thus, we have a Hamiltonian path.}
\alt<5>{\qedhere}{\phantom\qedhere}
\end{proof}
\end{frame}

\begin{frame}{More group theory and graph theory connections}
So far we have associated a graph with a group but we can go the other way. That is, we can associate a group with every graph. This group is called the automorphism group of a graph. \pause

We will be talking about the automorphism group of a graph, so we need to define new terms. From group theory, we know that an automorphism is an isomorphism from a group to itself. The set of automorphisms of a group forms a group called the \textbf{automorphism group} denoted $Aut(G)$. The elements of $Aut(G)$ are group isomorphisms. 

The appendix contains a proof that the automorphism group is a group under function composition.
\end{frame}

\begin{frame}{Graph Isomorphisms and Automorphisms}
\begin{block}{Definition: Graph Isomorphisms and Automorphisms}
\begin{itemize}
\item<1-> \textit{Graph isomorphism:} An isomorphism between graphs $G$ and $H$ is a bijection $\phi: V(G) \to V(H)$ s.t. $uv \in E(G)$ iff $\phi(u)\phi(v) \in E(H)$. Notice that this defines an isomorphism between the vertex sets of the graphs. In examples, we will see that the degree of the vertex also matters in defining an isomorphism.
\item<2-> \textit{Graph automorphism:} An isomorphism from a graph to itself. Formally, it is a bijection $\phi: V(G) \to V(G)$ s.t. $uv \in E(G)$ iff $\phi(u)\phi(v) \in E(G)$.
\end{itemize}
\end{block}
\end{frame}

We will denote the identity automorphism as $\epsilon$ with the map $u \to u, v \to v, x \to x, y \to y$. \pause

$\alpha$ has the map $u \to y, y \to u, v \to x, x \to v, w \to w$. We map $u \to y$ because these are the only elements of degree one and $v \to x$ because these were adjacent to the elements of degree one. So, $Aut(G)$ = $\{\epsilon, \alpha\}$. \pause

We can compose these using the group operation. But recall that $Aut(G)$ is a group and we know, from group theory, that the non-identity element is its own inverse in groups with two elements. Thus, $\alpha \circ \alpha = \epsilon$.
\end{frame}

\textbf{Conclusion:} $Aut(G) \cong \mathbb{Z}_{2}$. We have found an automorphism between a graph and a well-known group!
\end{frame}

\begin{frame}{Equivalence relation between two vertices in G}
Let $u, v \in V(G)$. We say $u \sim v$ if $\exists \space \phi \in Aut(G)$ s.t. $\phi(u) = v$. Two vertices are related if there is some graph automorphism that maps one vertex to the other. \pause

\textbf{Consequence:} We can partition the vertex set of a graph G. \smallskip

\begin{frame}{Free groups}
The point of this section is to add a rigorous explanation to the generators and relations discussion that began the talk. To begin, we will define some terms about free groups, which is the set that contains generators and relations.

Let $S = \{a, b, c, ...\}$ be a set of distinct symbols. As an example from permutation groups, $S$ would not contain both $(12)(13) = (123)$ because these are obviously not distinct. This concept of distinctness is important for free groups. \pause

Define $S^{-1} = \{a^{-1}, b^{-1}, c^{-1}, ...\}$ so that each element of $S$ has an inverse in $S^{-1}$. We define the set $W(S)$ to be the collection of all finite strings of the form $x_{1}x_{2}...x_{n}$ where each $x_{i} \in S \cup S^{-1}$. \pause

The elements of $W(S)$ are called words from $S$. Notice that this set contains every possible combination of elements in $S$ and $S^{-1}$.
\end{frame}

\begin{frame}{Facts about $W(S)$}
\begin{itemize}
    \item<1-> Contains an empty word (word with no elements) which also acts as the identity.
    \item<2-> Binary operation of $W(S)$ is concatenation. (e.g. $x_{1}x_{2}...x_{n}$ and $y_{1}y_{2}...y_{n}$ = $x_{1}x_{2}...x_{n}y_{1}y_{2}...y_{n}$
    \item<3-> For any two words in $W(S)$ the binary operation is associative. 
    $(x_{1}x_{2}...x_{n}y_{1}y_{2}...y_{n}) z_{1}z_{2}...z_{n} = x_{1}x_{2}...x_{n}(y_{1}y_{2}...y_{n} z_{1}z_{2}...z_{n})$
    \item<4-> Inverses are not as simple as $aa^{-1}$ because $a$ is just a symbol so $aa^{-1}$ has no meaning.
    \item<5-> We need to define inverses so $W(S)$ is a group; we can do this with equivalence classes.
\end{itemize}
\end{frame}

\begin{frame}{Proving an equivalence relation on $W(S)$}
\begin{block}{Definition: Equivalence class of words}
For any pair of elements $u$ and $v$ of $W(S)$, we say that $u$ is related to $v$ if $v$ can be obtained from $u$ by a finite sequence of insertions or deletions of words of the form $xx^{-1}$ or $x^{-1}x$ where $x \in S$.
\end{block}

\begin{block}{Example: $S = {\{a, b, c\}}$}
$acc^{-1}b$ is equivalent to $ab$ because we can obtain $ab$ by a deletion of the form $cc^{-1}$ where $c \in S$.
\end{block}
\end{frame}

\begin{frame}{Proving an equivalence relation on $W(S)$}
\textbf{Claim:} $u \sim v$ if $v$ can be obtained from $u$ by a finite sequence of insertions and deletions.
\begin{proof}
    To prove that $u \sim v$ is an equivalence relation we need to prove that it satisfies reflexivity, symmetry, and transitivity. \pause

    We know $u, v \in W(S)$ so denote these as $u_{1}u_{2}...u_{n}$ and $v_{1}v_{2}...v_{n}$. \pause

    \textit{Reflexivity ($u \sim u$):} $u_{1}u_{2}...u_{n} \sim u_{1}u_{2}...u_{n}$ because we can obtain $u_{1}u_{2}...u_{n}$ by applying no insertions or deletions. \pause

    \textit{Symmetry ($u \sim v \implies v \sim u$):} If $u_{1}u_{2}...u_{n} \sim v_{1}v_{2}...v_{n}$ then there exists a finite sequence of insertions and deletions made to $u$ s.t. we obtain $v$, by definition. To get from $v$ to $u$ reverse the finite sequence which was used to obtain $v$ from $u$: delete the insertions and insert the deletions. \pause

    \textit{Transitivity ($u \sim v, v \sim w \implies u \sim w$):} If $u_{1}u_{2}...u_{n} \sim v_{1}v_{2}...v_{n}$ and $v_{1}v_{2}...v_{n} \sim w_{1}w_{2}...w_{n}$ then there exist two different finite sequences of insertions and deletions. Concatenate these two sequences together; this result is exactly the relation $u \sim w$.
\end{proof}
\end{frame}

\begin{frame}{Equivalence classes of $W(S)$ form a group}
\begin{theorem}
    Let S be a set of distinct symbols. For any word $u$ in $W(S)$, let $\bar{u}$ denote the set of all words in $W(S)$ equivalent to u (i.e., $\bar{u}$ is the equivalence class containing u). Then the set of all equivalence classes of elements of $W(S)$ is a group under the operation $\bar{u} \cdot \bar{v} = \bar{uv}$.
\end{theorem}

\begin{itemize}
    \item<1-> The elements of this group are \textbf{sets}. These sets are equivalence classes that partition $W(S)$.
    \item<2-> This group is called a free group on S because it contains no additional relations which do not follow from the group axioms. As an example, it does not contain something like $ab = ba$.
\end{itemize}

\end{frame}

\begin{frame}{Universal Mapping Property}
\begin{theorem}
    Every group is a homomorphic image of a free group.
\end{theorem}

\begin{proof}
\only<1>{Let $G$ be a group, and let $S$ be a set of generators for $G$. Now, let $F$ be the free group on $S$.}

\only<1>{Before we continue the proof, we develop some notation to distinguish between the words in $W(S)$ and elements of $G$. We will denote the word $x_{1}x_{2}...x_{n}$ in $W(S)$ by $(x_{1}x_{2}...x_{n})_{F}$ and the product in $G$ by $(x_{1}x_{2}...x_{n})_{G}$. $\overline{x_{1}x_{2}...x_{n}}$ is the equivalence class in $F$ containing the word $(x_{1}x_{2}...x_{n})_{F}$.}

\only<1>{The elements $\overline{x_{1}x_{2}...x_{n}}$ and $(x_{1}x_{2}...x_{n})_{G}$ are different elements because the operations on $F$ and $G$ are different. We know that the operation of $F$ is the concatenation of the elements of the equivalence classes; the operation of $G$ is unknown.}

\only<2>{Consider the mapping from $F$ to $G$ given by: $\phi \overline{(x_{1}x_{2}...x_{n})} = (x_{1}x_{2}...x_{n})_{G}$. This maps the product of elements which form an equivalence class in $F$ to the product in $G$.}

\only<2>{Note that $\phi$ is well-defined, because inserting or deleting expressions of the form $xx^{-1}$ or $x^{-1}x$ in elements of $W(S)$ corresponds to inserting or deleting the identity in G. Recall that we said that the inverses of symbols in $F$ do not have any formal meaning \textit{but} a product $x^{-1}x$ does have meaning inside of a group; those elements combine to give the identity (by group axioms).}

\only<3>{We can check that $\phi$ is operation-preserving, observe that $\phi \overline{(x_{1}x_{2}...x_{n})(y_{1}y_{2}...y_{n})} = \phi \overline{(x_{1}x_{2}...x_{n}y_{1}y_{2}...y_{n})} = (x_{1}x_{2}...x_{n}y_{1}y_{2}...y_{n})_{G} = (x_{1}x_{2}...x_{n})_{G}(y_{1}y_{2}...y_{n})_{G}$.}

\only<3>{We move from the second to the third equality using the map $\phi$ and we get the last equality by the closure of $G$. Lastly, $\phi$ is onto G because $S$ generates $G$.}
\alt<3>{\qedhere}{\phantom\qedhere}
\end{proof}

\only<3>{\textbf{Takeaway:} We have defined a free group on a set of generators and we found a homomorphic map which maps \textit{onto} the group G. This shows that we can "hit" every element in G without any relations.}
\end{frame}

\begin{frame}{Universal Factor Group Property}
    \only<1>{\textbf{Takeaway 2:} The Universal Mapping Property (UMP) provided an onto function from $F \to G$ but this map can be smaller than $G$ (if $G$ is not taken to be the generating set) or larger than $G$. It may be larger since $F$ contains all combinations of symbols, and some of these symbols might be redundant based on the relations of $G$.}

    \only<1>{If we want to reconstruct $G$ from a free group, we need the following theorem.}

    \only<1>{\begin{theorem}
        Every group is isomorphic to a factor group of a free group.
    \end{theorem}}

    \only<1>{We will not prove this; let us instead understand the theorem.}

    \begin{block}{Understand the UFG Property}
        \only<1> {Recall the First Isomorphism Theorem for groups: Let $\phi$ be a group homomorphism from $G$ to $\bar{G}$. Then the mapping from $G/Ker\phi$, given by $gKer \to phi(g)$, is an isomorphism. In symbols $G/Ker \phi \cong \phi(G)$.}

        \only<2>{We want a homomorphism so we can use the First Isomorphism Theorem for groups. To get a homomorphism use the identity map $f: G \to G$. Every map of sets $f: G \to G$ extends to a unique homomorphism $\phi: F \to G$ if the generators of the domain are sent to the generators of the codomain. But this is obviously the case in $f$ since each element of $G$ is sent to itself.}

        \only<2>{Now we have a homomorphism $\phi$. The definition of $Ker\phi = \{f \in F | \phi(f) = e_{G}\}$ says that we take any element of the free group and the homomorphism sends this element to the group identity.}

        \only<3>{We saw something like this earlier. When we first began talking about relations these were defined as $\langle element = element = ... = e \rangle$. From the takeaway of UMP we know that $F$ contains all combinations of elements of $G$ with no additional relations. But the $Ker\phi$ is naturally the set of relations for $G$ since it sends these combinations from $F$ to the groups' identity.}

        \only<3>{Thus, $F/Ker\phi \cong G$.}
    \end{block}
\end{frame}

\begin{frame}{Generators and Relations Definition}
    We now have enough understanding to define generators and relations.
    \begin{block}{Generators and Relations}
        Let $G$ be a group generated by some subset $A = \{a_{1}, a_{2}, ..., a_{n}\}$ and let $F$ be the free group on $A$. Let $W = {w_{1}, w_{2}, ..., w_{t}}$ be a subset of $F$ and let $N$ be the smallest normal subgroup of $F$ containing $W$. We say that $G$ is given by the generators $a_{1}, a_{2}, ..., a_{n}$ and the relations $w_{1}, w_{2}, ..., w_{t} = e$ if there is an isomorphism from $F/N$ onto $G$ that carries $a_{i}N$ to $a_{i}$.
    \end{block}

    \pause

    \begin{itemize}
        \item We define the free group on a set of distinct generators $A$.
        \item Relations are in a normal subgroup ($Ker\phi$ is normal so this aligns with First Isomorphism Theorem intuition).
        \item We needed the quotient group corollary to define an isomorphism from the factor group with $F \to G$.
    \end{itemize}
\end{frame}

\begin{frame}{Appendix: Proof that the automorphism group is a group}
\textbf{Claim: The automorphism group is a group.}
    \begin{proof}
        Let $Aut(G)$ be the automorphism group of $G$. We want to show that this is a group. First, we note that the identity map (the map that takes each element of $g$ in the domain to its corresponding $g$ in the codomain) is an element of $Aut(G)$ by definition. This map is 1-1, onto, and operation preserving. Thus, we have an identity element of $Aut(G)$.

        Next, let $\varphi: G \to G$, $\lambda: G \to G$ $\in Aut(G)$. We want to show that $(\varphi \circ \lambda)(g) \in G$. $\lambda (g) = g$ in $\lambda: G \to G$. So $g$ is an element of the codomain of $\lambda$ that is the input to $\varphi$. Then $\varphi(g) = g$ by its map. Thus, we have closure.

        For inverses, let $\varphi: G \to G \in Aut(G)$. By the definition of Aut(G) $\varphi$ is an isomorphism. By Theorem 6.2, property 1 (Gallian 10th edition) $\varphi^{-1}$ exists and is an isomorphism from $G \to G$. Lastly, the associative property is inherited from the definition of function composition.
    \end{proof}
\end{frame}
